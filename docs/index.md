# grok_build_switch

`grok_build_switch` 是一个 Windows 托盘与 macOS 菜单栏工具，用来管理 Grok Build 的 `config.toml`。你可以把不同上游、API Key、默认模型、联网搜索模型和 subagents 模型保存成供应商 Profile，然后一键切换。

## 快速入口

- [使用教程](usage.md)
- [macOS 适配仓库](https://github.com/xingranya/grok-build-switch)
- [上游项目](https://github.com/1parado/grok-build-switch)
- [联系方式](contact.md)

## 它适合做什么

- 管理多个 Grok Build 上游配置
- 在不同供应商、模型和 API Key 之间快速切换
- 自动备份切换前的 `config.toml`
- 通过本地 Web 面板完成配置和编辑
- 使用 Windows 托盘或 macOS 菜单栏快速打开面板、切换供应商和管理登录时启动

## 下载

Windows 版本可从上游 [Releases](https://github.com/1parado/grok-build-switch/releases) 下载。macOS Apple Silicon 版本由适配仓库的 `Build macOS app` 工作流生成 `.app` 与 DMG。
